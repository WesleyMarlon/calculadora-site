# Calculadora de Custos e Lucros

Calculadora web para estimar o custo de produção e o lucro de produtos e receitas.

## Funcionalidades

- Cálculo proporcional do custo dos ingredientes e materiais utilizados.
- Adição e remoção de produtos.
- Soma automática dos custos.
- Cálculo do custo por unidade e do lucro estimado.
- Tema escuro.

## Tecnologias

- HTML
- CSS
- JavaScript
